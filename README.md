# Dijkstra Algorithm – Smart Navigation System
## Project Description
This project implements **Dijkstra's Shortest Path Algorithm in C** to find the shortest route between different locations in a smart navigation system.
The locations are represented as **vertices (nodes)** and the distances between them as **weighted edges**.

## Objective
* Implement Dijkstra's algorithm in C.
* Find the shortest path between two locations.
* Understand the application of graphs and weighted edges.
* Develop a basic smart navigation system.

## Locations
The system includes 7 locations:
* Airport
* Railway Station
* City Mall
* Bus Stand
* Hospital
* College
* Stadium

## Algorithm
Dijkstra's algorithm finds the shortest path from a selected source to a destination in a weighted graph with non-negative edge weights.

### Steps
1. Select the source location.
2. Set its distance to 0 and other distances to infinity.
3. Select the unvisited node with the smallest distance.
4. Update the distances of its neighboring nodes.
5. Mark the node as visited.
6. Repeat until the destination is reached.
7. Display the shortest route and total distance.
